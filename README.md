
# Brazil eCommerce Delivery Analytics  
Introduction
This project focuses on analyzing the delivery performance of a large Brazilian e
commerce marketplace using the publicly available Olist ECommerce Dataset 
from Kaggle.
The goal of this project is to build an interactive Tableau dashboard that provide 
insights into customer behavior, order patterns, delivery performance, product 
demand, and seller activity.
The dataset contains 8 relational tables, and we are using:
olist_orders_dataset – order timestamps and delivery status   and 
olist_order_items_dataset – item-level details including freight and shipping
olist_products_dataset - product details
These tables were cleaned, prepared, and integrated to build a complete end-to
end Tableau project.
Key Insights 
Sales Grew Steadily by the year end of 2016 and reached the Top of sales at 
the Mid of 2017 and Dropped by the end of 2018 due to data limitations or 
operational issues.
Top categories show consumers prefer beauty, health, and home goods.
2016 had zero late deliveries, 2017 saw a moderate increase, and 2018 
experienced the highest number of late deliveries.this indicates a decline in 
delivery performance over the years.ˮ
